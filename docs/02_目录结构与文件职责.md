# 02 目录结构与文件职责

## 2.1 仓库总览

```
banking-agent/
├─ .env                 # 本地凭据，永不提交（已在 .gitignore）
├─ .env.example         # 变量清单
├─ .gitignore
├─ Makefile             # 唯一入口，所有命令都从这里进
├─ README.md            # 对外说明（提交物之一）
├─ PROGRESS.md          # 每个里程碑一行，交接必读
├─ requirements.txt
├─ setup_env.sh         # 从 /home/peng/.dsh/.env 抽 key 生成 .env
├─ app/                 # 后端（FastAPI + SQLite + 纯 Python 逻辑）
├─ web/index.html       # 单文件前端（内联 CSS/JS，无构建）
├─ tests/               # pytest，全部可离线跑
├─ scripts/             # 红队、演示剧本、压测
└─ docs/                # 本套规格书 00—10
```

## 2.3 放置规则：新逻辑该写在哪

| 你要写的逻辑 | 放哪 | 判断依据 |
|---|---|---|
| 该不该允许这个操作 | `policy/engine.py` + `policy/rules.py` | 纯函数、无 IO |
| 真正动数据/动钱 | `tools/*.py` | 需要 token |
| 理解用户说什么、拆几步 | `planner/*` | 会调 LLM |
| 处理外部不可信字符串 | `guard/*` | 只标记不决策 |
| 拼 HTTP / 推流 | `api/*` | 不写业务 |
| 界面上怎么显示 | `web/index.html` | 不参与决策 |
