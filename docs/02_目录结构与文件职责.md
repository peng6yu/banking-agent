```

├─ .env                 # 本地凭据，永不提交（已在 .gitignore）
```

## 2.3 放置规则：新逻辑该写在哪

| 你要写的逻辑 | 放哪 | 判断依据 |
|---|---|---|
| 该不该允许这个操作 | `app/policy/engine.py` + `app/policy/rules.py` | 纯函数、无 IO |
| 真正动数据/动钱 | `app/tools/*.py` | 需要 token |
| 理解用户说什么、拆几步 | `app/planner/*` | 会调 LLM |
| 处理外部不可信字符串 | `app/security/*` | 只标记不决策（注入/信封/熔断/令牌都在这一层；`guard/*` 目录整体没建） |
| 拼 HTTP / 推流 | `app/api/*` | 不写业务 |
| 界面上怎么显示 | `web/index.html` | 不参与决策 |

## 2.4 新增文件的三个动作（缺一视为未完成）

1. 在 2.2 表里加一行（职责 / 导出 / 依赖 / 禁止）。
2. 在 `tests/test_imports.py` 的允许依赖表里登记。
3. 在 `PROGRESS.md` 追加一行说明为什么新增。
