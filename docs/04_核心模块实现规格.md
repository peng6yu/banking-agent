# 04 核心模块实现规格（逐函数分支表）

> 本章的每个函数都必须按分支表实现。分支表里没写的情况**不要自己补**，按「默认拒绝 / 抛错」处理，然后写进 `docs/QUESTIONS.md`。

## 4.1 clock.py —— 统一时间源

```python
def now_ms() -> int          # 当前 Unix 毫秒
def now_s() -> int           # 当前 Unix 秒
def freeze(ts_ms: int)       # 测试用，冻结时间
def unfreeze()
```

| 条件 | 行为 |
|---|---|
| 未冻结 | 返回 `int(time.time()*1000)` |
| 已冻结 | 返回冻结值，且**不随时间前进** |

铁律：全项目禁止 `datetime.now()` / `time.time()`，只许调这里。（`llm.py` 里测延迟的 `time.time()` 例外，已在代码里注明）

## 4.2 errors.py —— 异常层级

```
AppError
├─ ValidationError      输入不合法
├─ MissingCapability    执行缺 token          → HTTP 403
├─ TokenExpired         令牌过期             → HTTP 403
├─ TokenMismatch        令牌与参数不匹配     → HTTP 403
├─ PolicyDenied         策略拒绝             → HTTP 403
├─ InsufficientFunds    余额不足             → HTTP 409
├─ HoldExpired          冻结已过期           → HTTP 409
├─ InjectionDetected    注入命中             → HTTP 400
└─ BreakerOpen          熔断中               → HTTP 429
```

| 规则 | 说明 |
|---|---|
| 每个异常带 `code: str` 与 `user_text: str` | `user_text` 是给用户看的中国话，不含技术细节 |
| 禁止 `except Exception` 后静默 | 必须 `raise` 或转成上述之一 |
| API 层统一映射 | 见 07 章的分支表 |

## 4.3 money.py —— 金额

```python
def to_fen(yuan: float | int | str) -> int
def fmt_yuan(fen: int) -> str            # 1286050 -> '12,860.50'
def parse_amount(text: str) -> int       # 自然语言 -> 分
```

### `to_fen` 分支表

| 输入 | 行为 |
|---|---|
| int / 纯整数 str | 乘 100，返回 int |
| 小数 str | `Decimal(s)` 后乘 100，**必须整数**，否则抛 `ValidationError('精度超过分')` |
| float | 先 `Decimal(str(x))`，同上 |
| 负数 | 抛 `ValidationError('金额必须为正')` |
| 0 | 抛 `ValidationError('金额必须大于 0')` |
| > 100 万元 | 抛 `ValidationError('单笔超过 100 万元')` |

### `parse_amount` 分支表（中文口语必须支持）

| 输入样例 | 返回（分） | 依据 |
|---|---|---|
| `500` / `五百` / `500块` / `500元` | 50000 | 阿拉伯或中文数字 |
| `五百五` | 55000 | 口语省略单位「十」→ 十位 |
| `一千二` | 120000 | 省略单位「百」→ 百位 |
| `500.5` / `五百五毛` | 50050 | 角 |
| `两块五` | 250 | 口语小金额 |
| `全部` / `所有钱` | 特殊值 `-1` | 由调用方替换成余额，**不允许在 money 里查库** |
| 空串 / 无法识别 | 抛 `ValidationError('没听懂金额')` | — |

实现建议：先用正则抓阿拉伯数字与单位，再对纯中文走一张字符映射表 `{零:0,一:1,...,十:10,百:100,千:1000,万:10000}`，按位累加。**不要引入 `cn2an` 之类外部依赖**，20 行能写完，且行为可控。

### `fmt_yuan` 分支表

| 条件 | 行为 |
|---|---|
| fen 为负 | 前置负号 |
| 小数部分为 0 | 仍保留 `.00`（银行界面惯例） |
| 千分位 | 必须加逗号 |

## 4.4 ids.py

```python
def new_id(prefix: str) -> str   # 如 new_id('a') -> 'a_3f9c1b2e'
```

| 条件 | 行为 |
|---|---|
| prefix 不在白名单 | 抛 `ValidationError` |
| 生成碰撞 | 概率极低，不重试；DB 主键冲突会自然暴露 |

## 4.5 models.py —— 数据契约（**字段名不许改**）

```python
class Action(BaseModel):
    tool: str
    params: dict[str, Any]
    account_id: str
    amount_fen: int | None = None
    source: Literal['user','agent','system'] = 'agent'
    untrusted_fields: list[str] = []      # 哪些参数来自外部不可信文本

class Decision(BaseModel):
    level: Literal['green','yellow','red']
    rule_id: str
    reason_code: str
    reason_text: str                      # 给用户看的一句中国话
    required_factors: list[str] = []      # red 时为空则视为配置错误
    limit_fen: int | None = None
    spent_today_fen: int | None = None

class DAGNode(BaseModel):
    id: str                               # n1 n2 ...
    tool: str
    params: dict[str, Any]
    depends_on: list[str] = []
    state: Literal['pending','running','waiting_confirm','waiting_factor','done','failed','skipped'] = 'pending'

class Dag(BaseModel):
    id: str
    nodes: list[DAGNode]

class ToolResult(BaseModel):
    ok: bool
    data: dict[str, Any] = {}
    error_code: str | None = None
    error_text: str | None = None
    audit_seq: int | None = None

class ChatRequest(BaseModel):
    session_id: str | None = None
    text: str = Field(min_length=1, max_length=500)

class ConfirmRequest(BaseModel):
    session_id: str
    confirmation_id: str
    approve: bool
    factor: str | None = None             # 人脸/短信/U盾
```

| 规则 | 说明 |
|---|---|
| 所有模型 `model_config = ConfigDict(extra='forbid')` | 多传字段直接报错，防止前端偷偷塞参数 |
| 金额字段一律 `int` 且以 `_fen` 结尾 | 评审会看这一点 |
| `Decision.reason_text` 必须能直接展示给用户 | 不要写英文、不要写代码 |

## 4.6 db.py

```python
def connect(path: str | None = None) -> sqlite3.Connection
@contextmanager
def tx(conn) -> Iterator[sqlite3.Connection]
def init_db(conn) -> None            # 执行 schema.sql，幂等
def sweep_expired_holds(conn) -> int # 返回释放条数
```

### `tx` 分支表

| 条件 | 行为 |
|---|---|
| 当前无事务 | `BEGIN IMMEDIATE` … 成功 `COMMIT`，异常 `ROLLBACK` |
| 已在事务中 | 用 `SAVEPOINT`，只回滚本段（嵌套安全） |
| 异常 | 回滚后原样抛出，**不许吞** |

### `sweep_expired_holds` 分支表

| 条件 | 行为 |
|---|---|
| `status='held'` 且 `expires_ms < now` | 改 `expired`，写 `transfer.released` 审计 |
| 否则 | 跳过 |
| 返回 | 处理条数（0 也算正常） |

启动时调一次，之后每 30 秒一次（`main.py` 里起 `asyncio` 任务）。

### `append` 分支表

| 条件 | 行为 |
|---|---|
| `event_type` 不在闭集 | 抛 `ValidationError` |
