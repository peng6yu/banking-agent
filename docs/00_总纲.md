# 00 总纲：这套文档怎么用

## 0.1 读者

本文档面向**另一个模型或另一位工程师**，假定对方没有任何口口相传的背景。读完 00—10 即可独立把项目写完，不需要回来问。

## 0.2 项目一句话

银行 AI 智能体：用自然语言替用户操作银行账户，且**保证模型被劫持也动不了钱**。

## 0.3 强制阅读顺序

`01 架构` → `02 目录` → `03 数据库` → `04 核心模块` → `05 安全层` → `06 工具与场景` → `07 规划器与前端` → `08 编码规范` → `09 工作区与Git` → `10 测试与验收`

## 0.4 十条铁律（违反即返工）

| # | 铁律 | 检查方式 |
|---|---|---|
| 1 | 安全判定不许写在 prompt 里。所有 allow/deny 由 `app/policy/engine.py` 的纯函数产出，入参是结构化 action，出参是 Decision | code review + `tests/test_policy.py` |
| 2 | 执行器只认 token。`app/tools/*` 每个执行函数第一行就是 `require_token(...)`，无 token 抛 `MissingCapability`。**不许留内部跳过校验的后门**，测试也走同一路径 | `tests/test_token.py` + `tests/test_tools_write.py` |
| 3 | 金额只用整数分。禁止 float 参与任何金额运算 | `grep -n float app/money.py` 为空 |
| 4 | 审计只增不改。任何写操作必须同事务写一条 audit_log；UPDATE/DELETE 由 SQLite 触发器拦截 | `tests/test_audit.py` |
| 5 | 结构化输出只走 tool_calls。**不要用 JSON mode**，实测 MiniMax 不遵守 | `grep -rn response_format app/` 为空 |
| 6 | 每个函数按各章的分支表实现，不允许'顺便处理一下'的隐式分支 | code review |
| 7 | 任何外部字符串（转账备注、商户名、转发内容）进模型前必须包信封并标记为数据 | `app/security/envelope.py` |
| 8 | 不许裸 except、不许 print、不许 `datetime.now()`（用 `app/clock.py` 的 `now_ms()`） | `make lint` |
| 9 | 前端单文件，不引入构建链 | 目录里只有 `web/index.html` |
| 10 | 每个 milestone 结束必须 `make test` 绿 + `make redteam` 全拦，才能进下一个 | `PROGRESS.md` |

## 0.5 里程碑与完成定义（DoD）

| 里程碑 | 内容 | 完成定义（必须能跑出来） |
|---|---|---|
| M0 | 环境与骨架 | `make smoke` 4/4 PASS |
| M1 | 数据层 | `make seed` 后 17 张表有数据、300 条流水；`make verify` 输出链完整 |
| M2 | 策略引擎 | `make test` 中 policy 全绿，含边界 1000 / 1000.01 |
| M3 | 能力令牌 | token 篡改/过期/换参/换工具/重放 全部被拒 |
| M4 | 工具层 | 无 token 直调执行器抛异常；hold 超时自动释放 |
| M5 | 意图与 DAG | 模糊表达能出 DAG；环依赖报错而不是死循环 |
| M6 | 执行器与 API | `curl` 打 `/chat` 能流式收到 trace/confirm/done |
| M7 | 决策剧场前端 | 浏览器里完成一次转账全流程并看到五块面板 |
| M8 | 红队与交付 | 43 条红队用例：PASS 29 / FAIL 14（离线 ScriptedAdapter 实跑；以 `python3.12 -m scripts.redteam` 最终实跑为准）；README、技术文档、安全自评齐 |

## 0.6 交接方式

1. 每完成一个里程碑：`git commit`，跑该里程碑的 DoD 命令，往 `PROGRESS.md` 追加一行（日期 / 里程碑 / 命令输出摘要）。
2. **文档冲突时以 `05 安全层` 为准**，安全优先级最高，其他章节让路。
3. 文档没写清的地方**不要自由发挥**：写进 `docs/QUESTIONS.md` 并停下来提问。
4. 任何为了'先跑起来'而临时绕过的安全校验，必须在代码里留 `# TODO(SECURITY)` 并在 `PROGRESS.md` 登记，否则视为未完成。
