## 规格核对

- 页数：13 页（要求 12–14 页）
- 累计口播时间：9:20 / 10:00（每页页脚标注「第 N / 13 页 · 累计 mm:ss / 10:00」）
- 版式：16:9，13.333 × 7.5 英寸（1920×1080 同比例）
- 配色：三色常量 绿 #16a34a / 黄 #d97706 / 红 #dc2626，另有深蓝 #0f2942 作底色
- 字体：微软雅黑（latin 与 ea 同时设置，避免中文回退成方块）
- 零外链：全文件无任何 http(s) 外链、无嵌入图片、无外部字体依赖，可离线放映

## 每页结构

## 口径纪律

- 页面上每个数字要么给出出处（页内灰色出处行），要么写成显式占位 __，没有编造的统计值。
